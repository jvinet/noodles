# Noodles

Noodles is a simple clipboard manager for Wayland.

- Listens for new items copied to the clipboard and saves them in RAM
- View and recall items in a dmenu/rofi/wofi-friendly format

Requires [Go](https://golang.org/) and
[wl-clipboard](https://github.com/bugaevc/wl-clipboard).

The simplicity and integration concepts are inspired from the
[cliphist](https://github.com/sentriz/cliphist) project. The only reason Noodles
exists is because I didn't want to store my clipboard items on-disk.
